📜 Overview
PDW-Bot is a multipurpose Discord bot built around a ! prefix. It combines:
* Moderation (ban, kick, timeout, purge, lock/unlock, mute, warn, infractions)
* Leveling & XP system (track activity, roles on rank-up, leaderboards)
* Giveaways with multiple winners
* Utility (ping, user/server info, cleanup)
* Fun (memes, dice rolls, trivia)
* Logging & Auto-mod (bad-word filtering, link blocking)
* Configurable via environment variables or a JSON/YAML config file
All admin commands require the proper Discord permissions (e.g. Ban Members, Kick Members, Manage Messages, etc.).

🔑 Permissions & Roles
* Bot needs:
    * Administrator (or at least Manage Channels, Manage Roles, Ban Members, Kick Members, Manage Messages, Timeout Members, Send Messages, Embed Links, Read Message History)
* Your staff roles should grant the matching Discord permissions:
    * Moderator role → Ban Members, Kick Members, Timeout Members
    * Helper role → Manage Messages (for purge), Manage Channels (for lock/unlock)
    * Administrator → All permissions, plus bot sensitive commands (announce, config)

📋 Command Reference
1. Moderation
Command	Perms Required	Description
!ban <@user> [reason]	Ban Members	Bans user, DMs them an embed (“You’ve been permanently banned…”) and logs in mod-logs.
!unban <userID>	Ban Members	Unbans user by ID, logs in mod-logs (“User has been unbanned.”).
!kick <@user> [reason]	Kick Members	Kicks user, DMs them an embed (“You’ve been kicked…”) and logs in mod-logs.
!timeout <@user> <duration>	Timeout Members	Applies a timeout (e.g. 10m, 2h, 1d, 1w), logs action.
!mute <@user> [duration]	Manage Roles	Assigns “Muted” role; optional auto-unmute after duration.
!warn <@user> [reason]	Manage Messages	Issues a warning, tracks in DB; use !infractions to list user’s warnings.
!infractions <@user>	Manage Messages	Displays a user’s recorded warns, kicks, bans, timeouts, etc.
!purge <number>	Manage Messages	Deletes the specified number of messages in the channel.
!lock / !unlock	Manage Channels	Toggles send-message permission for @everyone in the current channel.
2. Giveaways
Command	Perms Required	Description
!gstart <duration> <prize> <winners>	Administrator / Host	Starts a giveaway (e.g. !gstart 1h Nitro 2).
!gend <messageID>	Administrator / Host	Ends a running giveaway early.
!greroll <messageID> <winners>	Administrator / Host	Picks new winners from ended giveaway.
3. Leveling & XP
Command	Perms Required	Description
!xp <@user?>	Everyone	Shows your or another user’s current XP & level.
!leaderboard [page]	Everyone	Displays the server’s XP leaderboard.
!setlevelrole <lvl> <role>	Administrator	Automatically grants a role when a user hits a level.
4. Utility
Command	Perms Required	Description
!ping	Everyone	Bot’s latency.
!userinfo <@user?>	Everyone	Displays account/server join date, roles, avatar.
!serverinfo	Everyone	Server stats: members, channels, created date.
!help [command]	Everyone	Lists all commands or detailed help for one.
!announce <#channel> <message>	Administrator	Sends an embed announcement.
!suggest <text>	Everyone	Collects suggestions to a configurable channel.
5. Fun & Misc
Command	Perms Required	Description
!meme	Everyone	Fetches a random meme (Reddit API).
!roll <sides>	Everyone	Rolls a numbered dice (default 6 sides).
!cat / !dog	Everyone	Random cute animal pic.
!urban <term>	Everyone	Urban Dictionary lookup.
!trivia	Everyone	Starts a quick trivia question.
